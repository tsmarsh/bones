Simple and Powerful

# Initialize a new book project
bones init

# Build PDF
bones pdf

# Build EPUB
bones epub

# Generate audiobook
bones mp3

# AI-assisted editing
bones lineedit  # Style and consistency review
bones copyedit  # Grammar and clarity edits

Get Started in Minutes

Install via Homebrew (Recommended)

brew tap tsmarsh/bones
brew install bones

No sudo required • All dependencies included • Works on macOS and Linux

1

Install

Run brew install bones (Homebrew) or sudo make install (from source)

2

Initialize

Run bones init in your project directory

3

Write

Edit your chapters in the chapters/ directory

4

Build

Run bones pdf to create your book

Or install from source:

git clone https://github.com/tsmarsh/bones.git
cd bones
sudo make install

Quick start:

mkdir ~/my-book && cd ~/my-book
bones init
bones pdf
