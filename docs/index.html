Simple and Powerful

# Initialize a new book project
bones init

# Build PDF
bones pdf

# Build EPUB
bones epub

# Generate audiobook
bones mp3

# AI-assisted editing
bones lineedit  # Style and consistency review
bones copyedit  # Grammar and clarity edits

AI-Powered Editing

Line Editing

High-level developmental feedback on your manuscript.

  • Style and consistency review
  • Character voice checking
  • Pacing and narrative flow
  • World-building consistency
  • Loads context from style guides

Copy Editing

Sentence-level improvements with git-based workflow.

  • Grammar and punctuation fixes
  • Clarity and concision
  • Sentence flow and rhythm
  • Creates git branches for review
  • Selective merge capabilities

Works with Claude (Anthropic), GPT-4 (OpenAI), or local models (Ollama)

Get Started in Minutes

1

Clone

Clone the repository and navigate to it

2

Install

Run sudo make install to install Bones

3

Initialize

Run bones init in your project directory

4

Build

Run bones pdf to create your book

git clone https://github.com/tsmarsh/bones.git
cd bones
sudo make install
cd ~/my-book
bones init
bones pdf
